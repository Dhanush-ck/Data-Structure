## Breif Explanation
- Queue
     - Data insertion and deletion are performed through different ends.
     - Data insertion is done from the rear.
     - Data deletion is done from the front.
     - Works like an actual queue.
     - Follows FIFO (First In, First Out) principle.

- Circular Queue
     - A type of queue where the last position is connected back to the first position.
     - Data insertion is done from the rear.
     - Data deletion is done from the front.
     - When the rear reaches the last position, it wraps around to the first position if space is available.
     - Efficiently reuses empty spaces created after deletion.
     - Follows FIFO (First In, First Out) principle.
     - Avoids the wastage of space that can occur in a linear queue.
