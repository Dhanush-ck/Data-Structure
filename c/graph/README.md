## Breif Explanation
-Tree
     - non-linear hierarchical data structure
     - consists of nodes connected by edges
     - topmost node is called the root node
     - each node can have zero or more child nodes
     - used to represent hierarchical relationships and organize data efficiently

- Breadth First Search (BFS)
     - tree traversal technique that visits nodes level by level
     - starts from the root node and visits all nodes at the current level before moving to the next level
     - uses a queue data structure
     - useful for finding the shortest path in an unweighted graph

- Depth First Search (DFS)
     - tree traversal technique that explores as far as possible along each branch before backtracking
     - starts from the root node and explores one complete path before moving to another
     - uses a stack or recursion
     - commonly implemented using preorder, inorder, and postorder traversal in trees
